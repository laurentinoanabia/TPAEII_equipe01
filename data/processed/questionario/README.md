# Tabelas agregadas do questionário

Tabelas T1 a T11 da análise preliminar da Entrega 6 (n = 60, respostas de 28/10 a 15/11/2026), copiadas das saídas do script de análise da equipe. Não há respostas individuais aqui. Células com menos de 5 respondentes aparecem como `<5`.

O site lê uma síntese delas em `data/pesquisa.json`, gerado por `scripts/montar_painel_pesquisa.py`. Se a análise for refeita, copie as tabelas novas para esta pasta e rode o script de novo.
